## Before going live

- [ ] Set `SESSION_SECRET` (48+ random bytes), `NODE_ENV=production` and `VITE_PUBLIC_SITE_URL=https://your-domain`.
- [ ] Replace the [Company name], address and jurisdiction placeholders in the legal docs.
- [ ] `npm run build && npm run check && npm run check:bundle && npm test && npm run lighthouse`
- [ ] `npm run check:links -- --external`
- [ ] Put the SQLite file on a persistent disk and back it up.
- [ ] Submit the sitemap to Google Search Console.
